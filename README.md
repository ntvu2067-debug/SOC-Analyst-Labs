# SOC-Analyst-Labs
# 🛡️ SOC Analyst & Security Portfolio

Repository lưu trữ tài liệu kỹ thuật, bài thực hành và Write-ups trong quá trình học tập, rèn luyện hướng tới vị trí **SOC Analyst (Blue Team)**.

---
## 📁 Kho bài thực hành

Mọi bài phân tích và write-up chi tiết được phân loại trực tiếp trong các thư mục:
* `01-Network-Analysis/`: Phân tích pcap, traffic mạng.
* `02-Endpoint-Investigation/`: Điều tra log máy trạm, mã độc.
* `03-TryHackMe-Writeups/`: Lời giải các phòng lab THM.


*Cập nhật liên tục trong quá trình học.*
