# SOC-Analyst-Labs
# 🛡️ SOC Analyst & Security Portfolio

Repository lưu trữ tài liệu kỹ thuật, bài thực hành và Write-ups trong quá trình học tập, rèn luyện hướng tới vị trí **SOC Analyst (Blue Team)**.

---

## 📌 Cấu trúc thư mục

* **`01-Network-Analysis/`**: Phân tích gói tin mạng, điều tra lưu lượng mạng với Wireshark và các giao thức mạng.
* **`02-Endpoint-Investigation/`**: Điều tra dấu vết hệ điều hành, phân tích Windows Event Logs, Sysmon và bộ nhớ RAM.
* **`03-TryHackMe-Writeups/`**: Ghi chép chi tiết và bài học rút ra từ các phòng lab trên nền tảng TryHackMe.
